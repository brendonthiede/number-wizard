# Number Wizard

A game that makes learning math fun and interactive.

## Features
- Adaptive difficulty
- Fun feedback and rewards
- Progress tracking and achievements
- Initial focus areas
  - Multiplication table memorization
  - Multiplying multi-digit numbers
  - Long division with remainders
  - Powers and exponents
- Use a Dungeons and Dragons-style adventure to make math practice more engaging
- Incorporate story-driven quests and challenges
- Include character progression and leveling up based on math performance
- Keep track of performance details to be used by AI for personalized learning and adaptive difficulty
